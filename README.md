Instructions for the running Classifying Song Genres from Audio Data

1. Go to the web browser install visual studio code.
2. Extract the zip file containing the source code of the web application.
3. Create a new folder and store the extracted file from the zip file.
4. To view the code, open folder from created folder in the visual studio code.
5. Check if the training code is available.  
6. To run the project we have to install all the requirements like required libraries.
7. Now click on the new Terminal and run the project. 
8. To run the project code is python manage.py runserver .
9. Now open any web browser and type the address as http://127.0.0.1:8000/.
10.Now Upload any music and click on predict.
11.The music genre and the prediction score is displayed.
